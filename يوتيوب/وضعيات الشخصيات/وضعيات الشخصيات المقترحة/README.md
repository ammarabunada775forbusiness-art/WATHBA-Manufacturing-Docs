# مراجع وضعيات الشخصيات

هذه الصور مراجع خارجية للحركة والوضعية فقط.

- لا يُنقل منها الوجه، أو الرأس، أو الشعر، أو الملابس، أو التشريح الخاص بالشخص الأصلي.
- لا يُنقل منها أسلوب الرسم أو لون الخلفية.
- تُطبّق هوية ذيب أو صخر وبصمة حبر WATHBA من المراجع الموجودة في مكتبة `وضعيات الشخصيات/`.
- يبدأ اسم كل مرجع خارجي برقم مثل `01` و`02` لتسهيل ترتيبه والرجوع إليه.
- هذا الترقيم خاص بالمراجع الخارجية فقط، ولا يُستخدم في أسماء صور ذيب وصخر النهائية.
- يصف باقي الاسم الحركة الموجودة في الصورة لتسهيل اختيار المرجع المناسب.

## تطبيق حركة إطالة الكتف — 2026-10-23

مرجع إطالة الكتف الذي أرسله عمار يُستخدم لتحديد مواضع الذراعين واتجاه الرأس فقط. لا يُنقل منه الجلد الأخضر، أو تمييز الدالية بالأحمر، أو ملامح الوجه، أو مظهر المجسم. نسخة صخر تُرسم بالأسلوب المشترك الجديد في مرجع الثبات 2.0 وبرباطين أبيضين، وتوضع على يمين ذيب في الصفحة الرئيسية.
