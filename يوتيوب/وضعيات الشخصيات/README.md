# مكتبة وضعيات شخصيات WATHBA

هذا المجلد هو المكتبة المركزية القابلة لإعادة الاستخدام لجميع وضعيات ذيب وصخر، ولا تُقسَّم الصور حسب رقم الفيديو.

## الهيكل

- `وضعيات الشخصيات/`: صور ذيب وصخر الجاهزة للاستخدام، إضافة إلى مراجع الهوية وأسلوب الخربشة.
- `وضعيات الشخصيات المقترحة/`: صور خارجية تُستخدم مرجعًا للحركة فقط.
- `مشاهد/`: مشاهد مركبة تحتوي أكثر من شخصية أو خلفية أو نص.

## قاعدة تسمية صور ذيب وصخر

- الاسم يكون بالعربية بالصيغة: `اسم الشخصية + وصف الحركة.png`.
- أمثلة: `ذيب يرفع كف التوقف.png` و`صخر عالق في العقلة.png`.
- لا يُضاف إلى الاسم رقم تسلسلي، أو رقم فيديو، أو عبارة `معتمدة`، أو رقم نسخة.
- إذا اقترح عمار اسمًا يختلف قليلًا عن الاسم المقترح، يُعتمد اسم عمار.
- الأرقام مسموحة داخل `وضعيات الشخصيات المقترحة/` فقط؛ لأنها ترتب المراجع الخارجية ولا تدخل في أسماء صور ذيب وصخر النهائية.

## طريقة العمل لكل فيديو

1. تُراجع مكتبة `وضعيات الشخصيات/` قبل إنشاء أي صورة جديدة.
2. تُحدَّد الوضعيات الموجودة التي يمكن إعادة استخدامها، ثم تُحدَّد الوضعيات الناقصة للفيديو.
3. تُنشأ الوضعيات الناقصة فقط، واحدة في كل مرة.
4. بعد قول عمار «تم»، تُضاف الصورة إلى المكتبة باسمها العربي الوصفي.
5. حالة المراجعة وتاريخ الاعتماد يُوثقان هنا أو في مرجع الثبات وسجل Git، ولا يوضعان داخل اسم الصورة.
