# مراجع وضعيات الشخصيات

هذه الصور مراجع للحركة والوضعية فقط.

- لا يُنقل منها الوجه أو الرأس أو الشعر أو الملابس أو التشريح الخاص بالشخص الأصلي.
- لا يُنقل منها أسلوب الرسم أو لون الخلفية.
- تُطبّق هوية ذيب أو صخر وبصمة حبر WATHBA من المراجع المعتمدة المنفصلة.
- الأسماء الوصفية تبيّن الحركة الموجودة في كل صورة لتسهيل اختيار المرجع المناسب.
